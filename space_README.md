# Fake Dataset Factory

Generate synthetic Normal and Pneumonia chest X-rays with Stable Diffusion,
DCGAN, WGAN-GP, VQ-VAE, DDPM, and Flow Matching v2.

This public demo runs on the free CPU tier. Diffusion and flow generation can
take a long time, especially when generating multiple images. Generated images
are synthetic research outputs and are not medical diagnoses.
